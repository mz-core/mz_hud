# mz_hud backups

Esta pasta guarda backups administrativos da configuracao global da HUD.

Arquivos gerados em runtime:

- `index.json`: indice dos ultimos backups conhecidos.
- `YYYYMMDD_HHMMSS_0000.json`: snapshot da configuracao global.

Nao edite estes arquivos manualmente enquanto o servidor estiver rodando.
Use os comandos administrativos documentados em `docs/BACKUPS.md`.
